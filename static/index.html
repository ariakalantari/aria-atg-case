How it works

Five steps, and Harry only ever answers small questions.

  1. FetchThe three most recent finished games from ATG's racing API.
  2. CleanDrop scratched horses, flag disqualified ones and sort each leg by V-odds.
  3. AskHarry first sees only the odds and names the favourites. Then it sees only the result and says where the favourite finished.
  4. VerifyCode works out the same answers from the raw data and marks each one.
  5. CountCode counts the win rate and median from Harry's own answers.

Harry AI can be wrong. Fact check important data.

The favourite is the horse with the lowest final V-odds. A disqualified favourite counts as finishing last. Foreign tracks only publish the top 3, so a finish outside it shows as "outside top 3".
